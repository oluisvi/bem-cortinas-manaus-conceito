# Bem Cortinas — prévia

Demonstração estática, mobile-first, criada a partir de informações fornecidas pela empresa. Abra `index.html` para visualizar localmente.

A página encaminha os pedidos para o WhatsApp comercial registrado. Não possui backend, agendamento ou sistema de orçamento. Imagens e paleta são ilustrativas; ver `ASSET_CREDITS.md` e `BRIEF_DO_PROJETO.md`.
